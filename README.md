# Simple Login Page

A simple login page with an Arabic interface, made to practice HTML and CSS forms and layout.

## Features
- Login form with styled inputs and button
- Right-to-left Arabic layout

## Built with
HTML, CSS

## Run locally
```bash
git clone https://github.com/moh9180812-cyber/Simple-Sign-Up-Project.git
cd Simple-Sign-Up-Project
```
Open `index.html` in your browser. No build step or install needed.
